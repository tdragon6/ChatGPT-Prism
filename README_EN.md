# ChatGPT Prism

[](assets/banner.svg)

<h4 align="center">
    ChatGPT Prism lets you configure startup animations for the ChatGPT/Codex desktop clients, supporting Windows and Darwin. While running in the background, it continuously hooks into the startup windows of newly launched client processes during cold starts. It supports switching between animations in the library, customizing parameters, importing local creations, and accessing the community marketplace

## Community Marketplace

- **Creation Skill**: The project includes a creation Skill [](skills/prism-work-create). Use it with your own ideas to generate startup animation packages organized in the directory format required by ChatGPT Prism
- **Local Import**: Import local creation directories into ChatGPT Prism without relying on the online community marketplace
- **Community Marketplace**: Install creations directly from the community marketplace within ChatGPT Prism. The default index is [market-index.json](market-index.json). You can customize the index URL in Settings to make it easier to expand the collection and contribute community creations

## Disclaimer

ChatGPT Prism uses hooks during the cold-start phase of new client processes without modifying system files or any ChatGPT/Codex files. It is currently unclear whether OpenAI officially permits this behavior, so users should assess the risks before use.
